# AUT0-CH branding

| File | Use |
|---|---|
| `aut0-ch-mark.svg` / `aut0-ch-mark-1024.png` | Symbol: hex nut forming a slashed zero. Transparent. |
| `aut0-ch-mark-tile.svg` | Symbol on a white rounded tile (Apple touch icons). |
| `aut0-ch-wordmark.svg` / `aut0-ch-wordmark-2400.png` | Horizontal lockup for light backgrounds. |
| `aut0-ch-wordmark-reverse.svg` | Horizontal lockup for dark/navy backgrounds. |
| `aut0-ch-social-1280x640.png` | GitHub social preview (Settings → General → Social preview). |
| `source/` | Original AI-generated concept images (reference only). |
| `make_brand.py` | Regenerates the SVGs. Needs `fonttools` and the Montserrat 800 font file. |

Colors: navy `#1D3557`, teal `#2A9D8F`, slate `#457B9D`. Wordmark font: Montserrat ExtraBold (SIL Open Font License 1.1), converted to outlines, so no font file is needed to display it. The zero is always a teal slashed zero, never the letter O.
